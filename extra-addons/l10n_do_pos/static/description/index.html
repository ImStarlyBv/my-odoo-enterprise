Fiscal POS – República Dominicana

Permite emitir comprobantes fiscales (NCF) directamente desde el Punto de Venta de Odoo, cumpliendo con la normativa de la DGII.

Odoo 18  ·  v18.0.2.3.7

¿Qué hace este módulo?

Cuando instalas Fiscal POS (Rep. Dominicana), tu Punto de Venta queda conectado al sistema de facturación fiscal de tu empresa. Esto significa que cada venta genera automáticamente un NCF válido y una factura contable, sin que el cajero tenga que salir del POS ni hacer ningún paso extra.

🧾
Generación automática de NCF

El sistema asigna el comprobante fiscal correcto según el tipo de venta, sin intervención manual.

📄
Factura automática

Toda orden fiscal crea su factura en contabilidad de forma inmediata al cerrar la venta.

👤
Cliente por defecto

Si el cajero no selecciona cliente, la venta se registra a nombre de un cliente genérico configurable.

↩️
Notas de crédito

Permite aplicar notas de crédito fiscales directamente al momento del pago en el POS.

🗂️
Historial de órdenes

Puedes limitar cuántos días de ventas se muestran en el POS para mejorar el rendimiento.

🔒
Registro de seguridad

Cada NCF generado se guarda en un log para recuperar la operación si ocurre un fallo de red.

Requisitos antes de configurar

Importante: Este módulo necesita que ya tengas instalados y configurados los módulos Punto de Venta y Contabilidad Fiscal RD (l10n_do_accounting), incluyendo al menos una Secuencia Fiscal activa para el tipo de comprobante que usarás.
Requisito Dónde verificarlo
Módulo Punto de Venta instalado Aplicaciones → buscar "Punto de Venta"
Módulo l10n_do_accounting instalado Aplicaciones → buscar "Contabilidad RD"
Diario de POS marcado como Diario Fiscal Contabilidad → Configuración → Diarios → editar el diario del POS
Al menos una Secuencia Fiscal activa Contabilidad → Configuración → Secuencias Fiscales

Cómo configurarlo (paso a paso)

1 · Verifica el diario fiscal del POS

El POS solo activará las funciones fiscales si su diario de ventas está marcado como fiscal.

Contabilidad → Configuración → Diarios → selecciona el diario que usa tu POS → activa "Diario Fiscal"

2 · Abre la configuración del Punto de Venta

Ve al menú del POS y entra en su configuración:

Punto de Venta → Configuración → Ajustes

Selecciona el punto de venta que quieres configurar en el selector de la parte superior.

3 · Establece el cliente por defecto

Busca la sección Contabilidad dentro de los ajustes. Ahí verás el campo "Cliente por defecto". Este cliente se usará automáticamente cuando el cajero no seleccione ningún cliente en la venta.

Si dejas este campo vacío y el cajero no selecciona un cliente, la venta no podrá completarse en modo fiscal. Se recomienda usar un cliente genérico como "Consumidor Final".

4 · Configura el historial de órdenes (opcional)

En la sección de inventario/ajustes avanzados (visible solo para administradores técnicos) encontrarás la opción "Historial de órdenes". Puedes dejarlo en "Todas las órdenes" o limitarlo a un número de días para mejorar el rendimiento del POS cuando hay muchas ventas acumuladas.

5 · Crea o verifica las secuencias fiscales

Sin secuencias activas no se pueden emitir NCF. Verifica que existan secuencias en estado Activo:

Contabilidad → Configuración → Secuencias Fiscales

Cómo funciona durante una venta

  1. El cajero abre el POS y agrega productos El proceso es el mismo que en un POS normal. No hay diferencia visible en este paso.
  2. Selecciona el tipo de comprobante (Tipo Fiscal) En la pantalla de la orden aparece un botón para seleccionar el tipo fiscal (ej. "Consumo", "Crédito Fiscal"). El cajero debe seleccionarlo antes de cobrar.
  3. (Opcional) Selecciona o busca el cliente Si el cliente quiere su comprobante a su nombre (RNC), el cajero busca o crea el cliente en la pantalla de socios. Si no se selecciona ninguno, se usa el cliente por defecto configurado.
  4. Procesa el pago El cajero selecciona el método de pago (efectivo, tarjeta, etc.) y confirma. Si hay notas de crédito disponibles para el cliente, puede aplicarlas aquí.
  5. El sistema genera el NCF automáticamente Al confirmar la venta, el sistema asigna el siguiente NCF disponible de la secuencia fiscal correspondiente y crea la factura en contabilidad de forma automática.
  6. El recibo impreso incluye el NCF El comprobante que se entrega al cliente (impreso o digital) muestra el NCF, la fecha de vencimiento del comprobante y los datos fiscales requeridos por la DGII.

Tipos de comprobante disponibles

Los tipos de comprobante que aparecen en el POS dependen de las secuencias fiscales activas en tu empresa. Los más comunes son:

Tipo Cuándo usarlo
Consumo (B02) Ventas a personas físicas o clientes sin RNC que no necesitan deducir el ITBIS.
Crédito Fiscal (B01) Ventas a empresas o profesionales que necesitan deducir el ITBIS.
Nota de Débito (B03) Cuando se necesita incrementar el valor de una factura ya emitida.
Nota de Crédito (B04) Devoluciones o descuentos sobre facturas fiscales ya emitidas.
Gubernamental (B15) Ventas a entidades del gobierno dominicano.
Solo verás los tipos de comprobante que tengan secuencias fiscales activas en tu sistema. Si falta algún tipo, debes crear la secuencia correspondiente en contabilidad.

Preguntas frecuentes

¿Qué pasa si se agota una secuencia fiscal?
El sistema te avisará con un error al intentar procesar una venta. Debes ir a Contabilidad → Configuración → Secuencias Fiscales y crear una nueva secuencia del tipo correspondiente. Esto lo puede hacer el administrador o el contador.
¿Puedo usar este POS sin emitir comprobantes fiscales?
Sí. Si el diario del POS no está marcado como "Diario Fiscal", el POS funciona de manera normal sin generar NCF. Las funciones fiscales solo se activan cuando el diario está configurado como fiscal.
¿Las ventas del POS aparecen en el reporte 606?
Sí. Dado que cada venta crea una factura contable con su NCF, esas facturas quedan incluidas automáticamente en el reporte 606 de ventas que genera el módulo de contabilidad fiscal.
¿Qué pasa si se va la internet durante una venta?
El módulo guarda un registro del NCF generado antes de confirmar la orden. Si ocurre un fallo de red, al reconectarse el sistema puede recuperar la operación desde ese registro para evitar duplicar o perder el comprobante.
¿Puedo cambiar el cliente por defecto después de instalar?
Sí. Ve a Punto de Venta → Configuración → Ajustes, selecciona tu POS y cambia el campo "Cliente por defecto" en la sección de Contabilidad. Guarda los cambios y el próximo turno ya usará el nuevo cliente.
¿Cómo hago una devolución con nota de crédito?
En el POS, busca la orden original desde la pantalla de "Órdenes" (ícono de ticket). Selecciónala y usa el botón de devolución. El sistema te pedirá el motivo y generará automáticamente una nota de crédito (B04) vinculada a la venta original.
